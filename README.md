# Tidy Branches

Tidy Branches is a GitHub-aware branch cleanup tool for safely finding and deleting remote branches whose pull requests have already merged.

The project is being built as the `gh tidy-branches` GitHub CLI extension. The repository should be renamed to `gh-tidy-branches` before its first public extension release because GitHub CLI extension repositories must begin with `gh-`.

Development work is tracked in issues and lands through pull requests.
